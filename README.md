# SalalihiniSandeshaya
සැළලිහිණි සංදේශය යනු ශ්‍රී ලංකාවේ කෝට්ටේ යුගයේදී තොටගමුවේ ශ්‍රී රාහුල හිමියන් විසින් රචනා කරන ලද සංදේශ කාව්‍යයකි. කැලණියේ විභීෂණ දෙවියන්ට පණිවිඩයක් යැවීම සඳහා සැළලිහිණි කුරුල්ලෙකු යොදාගැනීම මෙහි ප්‍රධාන තේමාවයි. මෙහි කෝට්ටේ රාජධානියේ ස්වභාව සෞන්දර්යය, ආගමික ස්ථාන, සංස්කෘතිය සහ සමාජ තොරතුරු මනාව විස්තර කර ඇත.
